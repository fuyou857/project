### 4.2 问题详细分析

#### D001-D003：模态框关闭异常（已修复）

**问题描述**：
点击成本发票录入弹窗的"取消"按钮后，模态框无法正常关闭，遮罩层仍然停留在页面上，导致用户无法继续操作页面。

**根因分析**：
1. 组件使用了Framer Motion的`AnimatePresence`配合`exit`动画
2. 当`open`状态变为`false`时，组件立即返回`null`
3. 这导致`AnimatePresence`无法完成退出动画，DOM元素滞留在页面中
4. 虽然元素设置了`pointer-events: none`，但DOM仍存在且可能被检测为问题

**修复方案**：
```tsx
// 修复前
<AnimatePresence>
  {open ? (
    <motion.div exit={{ opacity: 0 }}>...</motion.div>
  ) : null}
</AnimatePresence>

// 修复后
if (!open) {
  return createPortal(null, document.body);
}
return createPortal(
  <motion.div initial={{ opacity: 0 }} animate={{ opacity: 1 }}>...</motion.div>,
  document.body
);
```

**修复效果**：✅ 通过，模态框关闭后DOM立即移除，无残留。

#### D004：Supabase API登录回退（已知问题）

**问题描述**：
尝试通过Supabase API注入会话时，会话注入后仍停留在登录页，需要回退到UI表单登录。

**影响评估**：
- 不影响用户登录功能（UI登录作为备选方案）
- 可能是测试账号或浏览器环境导致
- 不影响系统核心功能

**建议措施**：
1. 检查测试账号的Supabase会话配置
2. 确认浏览器隐私设置是否阻止localStorage
3. 添加更详细的登录失败诊断日志

#### D005：控制台405错误（已知问题）

**问题描述**：
浏览器控制台出现59条`Failed to load resource: the server responded with a status of 405`错误。

**影响评估**：
- 不影响核心功能（发票录入、模态框交互均正常）
- 可能是某些API端点不支持特定HTTP方法
- 不影响用户体验

**建议措施**：
1. 审查所有API端点的HTTP方法配置
2. 检查Nginx反向代理配置
3. 添加API错误监控和告警
