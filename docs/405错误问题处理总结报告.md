## 二、根本原因分析

### 2.1 问题定位

通过审查 Nginx 配置文件，发现问题根源：

**受影响的配置位置**：

1. `/supabase/functions/v1/` (第 42 行)
   ```nginx
   add_header Access-Control-Allow-Methods "GET, POST, OPTIONS" always;
   ```

2. `/api/contract-convert/` (第 70 行)
   ```nginx
   add_header Access-Control-Allow-Methods "GET, POST, OPTIONS" always;
   ```

### 2.2 影响分析

| 影响范围 | 说明 | 严重程度 |
|---------|-----|---------|
| Supabase Edge Functions | 部分调用可能受限 | 中 |
| 本地 Edge Functions | 文档转换服务 | 低 |
| 核心功能 | 不受影响 | - |
| 用户体验 | 控制台显示错误 | 低 |

---

## 三、解决方案

### 3.1 推荐修复方案

修改 Nginx 配置，扩展允许的 HTTP 方法：

```nginx
# 在两个位置都添加 PUT, PATCH, DELETE
add_header Access-Control-Allow-Methods "GET, POST, PUT, PATCH, DELETE, OPTIONS" always;
```

### 3.2 修复步骤

1. **备份配置**
   ```bash
   cp /www/wwwroot/ciond/nginx-full.conf /www/wwwroot/ciond/nginx-full.conf.bak.$(date +%Y%m%d)
   ```

2. **编辑配置**
   ```bash
   nano /www/wwwroot/ciond/nginx-full.conf
   ```

3. **测试配置**
   ```bash
   nginx -t
   ```

4. **重载 Nginx**
   ```bash
   nginx -s reload
   ```

### 7.2 缓解措施详情

- **预防措施**：
  - 完整的配置备份
  - 测试环境先行验证
  - 配置语法检查
  
- **应急预案**：
  ```bash
  # 立即回滚
  cp /www/wwwroot/ciond/nginx-full.conf.bak.20260519XXX /www/wwwroot/ciond/nginx-full.conf
  nginx -s reload
  ```

#### R002 - CORS 配置不当

- **预防措施**：
  - 遵循最小权限原则
  - 仅允许必要的 HTTP 方法
  - 定期审查 CORS 配置

- **安全建议**：
  ```nginx
  # 生产环境建议
  add_header Access-Control-Allow-Origin "https://www.ciond.com" always;
  add_header Access-Control-Allow-Methods "GET, POST" always;
  ```
